# What was rejected and why

| Rejected | Why it failed | Do instead |
|---|---|---|
| Glossy candy cards: thick navy outline, gloss swooshes, rays on every card, every card a different rarity colour | reads "AI slop" | flat style with black outlines, or material style |
| Designing from memory / small-game portfolios | looked terrible next to real big games | study screenshots of BIG games first |
| Side tabs in a shop | real big-game shops don't use them | one scroll with section pills |
| Hand-coded 2D SVG icons with line details | looked AI | toon 3D renders, or clean 2.5D with soft gradients |
| Smooth realistic 3D items | "AI slop", not Roblox | voxel with studs, or toon 3D |
| Chunky low-res voxels / no studs | too blocky, not Roblox | smaller voxels + studs on top faces |
| Items pasted on top of cards/crates | doesn't sit in the UI | recessed item windows / tiles with glow |
| Cute floating leaves and sparkles everywhere | childish, generated | one decoration idea per screen, sparkles placed by hand |
| Copying a reference layout | wants original | same language, own composition |

Process: look -> brief -> build -> compare side by side -> fix -> show. Send pictures often. Change only what the user points at.
